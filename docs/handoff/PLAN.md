# 后续方案与验收建议（尚未实施）

## 目标与约束

用官方Agent、技能和工具实现用户自然语言剪辑；用户换素材、换要求后仍由Agent自主选工具与片段。保留原声，支持必要粗剪、对应字幕、预览下载和历史。不能把人工挑片段、手写时间线或模拟模型回复当真实验收。

不重写编排器，不默认合并工具，不靠重复纠错消息让一次任务勉强成功。只改已复现的问题；一项补丁一组回归，先离线再付费。现阶段不接业务、不部署。

## 建议执行顺序

### 1. 固定可解释的基线

- 跑现有防覆盖回归；记录commit、diff、配置差异和依赖版本。
- 保持官方提示词/技能；创建新session，使用默认缓存根，避免旧结果和预览目录混淆。
- 核对模型官方探测兼容性，不偷偷改探测参数或临时切换模型；费用核验包含探测请求。

### 2. 先离线解决具体冲突

- **筛选**：用已保存的14段及真实选择回复复现；明确工具的“素材去重”与“按内容精剪”语义。候选最小方案：保留未明确精剪时的官方默认规则，仅在用户明确要求内容/数量/时长筛选时使其优先。此建议会改变提示词行为，需单独审查，不能直接删全部约束或写死行星数。
- **时间线**：先追踪split/ASR/filter/group/rough/timeline之间实际artifact来源。单纯选中clip IDs不等于句级剪辑，group不应重新引入已排除片段。新增生成应产生新记录，旧产物可读；避免全局覆盖“最新结果”。具体改动以离线复现为前提。
- **字幕**：先检查官方粗剪路径是否已满足需求；如需ASR直出字幕，需定义源片段时间→剪后片段时间→最终时间线偏移，保留原声转录而非另生成旁白。覆盖删除前段、多个源片段、连续保留段、时间界限、换行和中文字体。不要仅凭字幕轨非空就判定通过。
- **取消/预览**：用本地渲染测试，无需付费模型。验证取消前/中/后状态、迟到文件与历史登记；默认缓存下预览下载、路径边界正常。

### 3. 再进行一次受控真实验收

前提：相关离线检查通过且模型预算已确认。只发送自然语言目标及官方必要确认。Agent自主选择；所有模型子调用计量。发现明确失败就停止、定位，下一次付费运行必须有新的可验证假设；不自动纠错循环。

| 验收项 | 通过证据 |
|---|---|
| 内容与数量 | 按实际解说/片段计数两到三颗，不能仅数文件或屏幕上的标签 |
| 完整与连贯 | 去开场结尾、保留主语、避免半句、顺序正确 |
| 时长 | ffprobe确认45—70秒 |
| 原声 | 各剪辑区间音频与源片段比对，无额外配音/配乐 |
| 字幕 | 可见、中文正常、不越界，与原声文本及时间对齐 |
| 成片 | 全片解码无错误；浏览器预览与实际下载可用 |
| 历史 | 成功render已登记；重启后同记录、同文件、旧结果可读 |
| 重跑 | 单独后续授权测试：新输入不串旧artifact、旧产物不被覆盖 |
| 成本 | 主Agent、视觉、句级工具、探测、失败与在途请求均有口径 |

后续再覆盖不同本地素材和不同要求，才能讨论通用性，单一行星视频不够。

## 未来接入现有系统（只作设计备忘，未开发）

优先做独立剪辑服务适配，复用官方`build_agent`、MCP工具与ArtifactStore，不复制工具实现或逐个改造业务工具。

- **模型与计费**：在统一模型调用边界接现有网关/计费服务，覆盖主Agent与MCP sampling子调用。传递用户、任务、创作记录、模型和调用幂等ID；费用由实际usage归集，取消后的在途调用仍可对账。不得在此文档臆造已有接口或表名，接入前核对现有系统实现。
- **资源输入**：业务资产引用转换为本任务可读的受限本地路径；不可让模型任意读宿主机文件。区分素材版本、执行输入快照和产物文件。
- **执行记录**：画布节点引用剪辑任务，任务绑定输入快照、官方session/artifact、状态、事件和产物版本。重跑产生新执行，不覆盖旧记录；原画布变化不改历史创作。
- **状态**：区分排队、运行、渲染、取消中、失败、待核对、成功；只有产物可访问且登记成功才标成功。先明确官方实际可提供的事件，不伪造百分比。
- **资产/历史**：本地路径由业务产物存储适配转换为授权预览/下载引用，旧版本可追溯；删除创作不得删除共用源资产。
- **技能配置**：从后端读取允许的skills与工具适用范围，不在前端写死名称；保存执行所用技能版本。权限/计费与已有系统对齐。

接入前置条件：本地核心剪辑验收通过、取消/历史/产物闭环明确、完整成本可审计。80和202不属于当前工作范围。
