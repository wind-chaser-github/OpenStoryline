# 修改与测试历程

本文区分“官方入口”“官方代码未改”“没有人为指定技能或纠错”三件不同的事。下列实验不能混为一次成功验收，成本也不能简单拼成完整账单。

## 唯一保留的运行补丁

文件：`src/open_storyline/nodes/core_nodes/speech_rough_cut.py`。

原版在一次调用中处理多个ASR源片段，共用输出目录；每个源片段的文件序号和clip ID从0重置。FFmpeg使用覆盖模式，因此后一个源片段覆盖前一个。历史真实回复的离线回放返回8条记录，但只剩5个不同文件和5个不同ID，部分实际时长与记录不符。

修复：文件序号在这次调用内跨源片段累加，返回clip ID按本次累计结果编号。只修命名唯一性，不改模型判断、片段时间、字幕、历史结构或工具顺序。它不承诺跨执行幂等，也没有修复取消后孤立产物问题。

恢复时用原有真实回复与真实FFmpeg离线验证：

| 用例 | 原版 | 保留修复后 |
|---|---|---|
| 多源片段 | 8记录/5文件/5 ID，时长不匹配 | 8/8/8，时长匹配 |
| 单源片段 | 未单独作为失败点 | 3/3/3，时长匹配 |
| 空结果 | 未单独作为失败点 | 0/0/0 |

本仓库另附可移植的`tests/test_rough_cut_outputs.py`：以合成视频、固定决策测试实际节点和FFmpeg，覆盖多源（夹空结果）、单源、空结果。它是文件覆盖回归，**不是AI实测或模型能力证明**；不依赖私人视频，不调用模型。

- `editing_contract`、`content_scope`、`asr_subtitles`辅助模块。

这些内容已全部撤回，仅在原本地备份目录保留追查证据。不要重新恢复整套补丁来“快速通过”；后续每项修复须有独立原版复现与最小差异。

## 最新一次真实运行

- 输入：本地私人太阳系科普视频，186.325760秒，854×480，H.264/AAC；源文件前后哈希一致。
- 要求：45—70秒、两到三颗行星、完整有价值特点介绍、去开场与结尾、顺序/原声/中文字幕、不配乐/另配音/生成画面。
- 配置：既有兼容网关，LLM/VLM均gpt-4.1，超时180秒、重试0；独立目录和本机端口。保留官方1-token探测。
- 观察器：仅记录完整模型请求、回复、usage；约22万已报告tokens或100调用时阻止后续请求，在途可超阈值；异常停机。不改提示词、输出或工具参数。
- 人工输入仅初始要求和“确认，开始执行。”；没有指定技能、行星或时间区间，没有纠错追问。

实际路径：

`default_editing_workflow_skill → load_media → split_shots → local_asr → understand_clips → filter_clips → group_clips → plan_timeline_pro → render_video`

结果：14分镜、14段ASR；选片模型全部保留；时间线14段、字幕0、配音0、配乐0。发现语义失败时render已启动，官方取消阻止继续推理。本地渲染仍完成186.267007秒缓存文件，解码通过，14段音频与源片段相关系数均超过0.98。该文件不合格，也没有登记为成功产物。

已保存的12条历史与节点JSON在Web重启后保持一致，`turn_running=false`、`restore_degraded=false`。不能由此推断“成功成片及下载历史已验收”。
