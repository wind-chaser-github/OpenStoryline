## 接手时不要误解

- “生成了mp4”“工具无异常”“历史存在”都不等于剪辑符合要求。
- 保留原声不等于禁止粗剪；原画面标题不等于解说字幕。
- 官方主Agent选择工具，MCP节点中还可能有逐句/逐片模型调用；成本不能只数对话轮次。
- 最新失败有官方提示词与实际回复证据，但不能据此推断所有模型/技能/素材都失败。
- 本次移交并未授权继续高成本实测或修改生产环境；重新付费运行前应明确本轮目标和预算。
